# V0 - Original Version

This directory contains the original v0 implementation of rhyme-and-meter.

## Status

✅ Stable - maintained while v1 is being developed

## Building

```bash
cmake --preset v0-debug
cmake --build --preset v0-debug
ctest --preset v0-debug
```
